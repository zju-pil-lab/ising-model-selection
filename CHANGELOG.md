# Changelog

## 1.0.0 — 2026-09-15

- Public reimplementation of Figure 2 replica theory and full Ising simulations.
- Reference results: 32 theory points, 32,000 full-dimensional fits, and 2,048 thinning-audit fits.
- Both per-run and ratio-of-means precision conventions, with explicit equation and sampling assumptions.
- Complete experimental coefficients/graphs, reproducible seeds, checksums and numerical diagnostics.
- Separate immutable reference data and generated outputs, CLI workflow, 18 tests, Linux/macOS CI configuration, MIT license and citation metadata.

This release does not contain the original 2021 source code or original raw outputs.
